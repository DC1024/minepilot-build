MinePilot change log
====================

0.1.11-dev-mc26.2
-----------------

- Audited the 15.1 professional-companion, 15.2 workstation/transport,
  15.3 farm, and 15.4 machine matrices against production skills, controlled
  Forge contracts, and authorized live-model evidence. Added the detailed
  English-only `docs/PROFESSIONAL_COMPANION_MATRIX.md` and kept all formal
  M0--M4 gates honest.
- Added fair role labels to currently open vanilla menu slots (furnace,
  brewing, crafting, cartography, smithing, grindstone, anvil, enchanting,
  loom, stonecutter, merchant, and player inventory) so the model can bind
  inputs and outputs without relying on remembered slot numbers. Labels are
  hints only; exact menu revisions and vanilla validation remain mandatory.
- Fixed foundation placement classification for brewing stands, cauldrons,
  fletching tables, hoppers, dispensers, droppers, observers, pistons,
  repeaters, comparators, and redstone lamps; added a focused regression test.
- Added a fair natural-End ingress controller with fresh terrain evidence,
  bounded observed mining, bridge/tower recovery, and Forge 65.0.0/65.1.1
  physical GameTest passes.
- Unified the dragon handoff around current natural End-stone rally evidence
  and raised the shared End combat reserve to 64 arrows with bow durability
  validation.
- Added route-guide coverage for `reach_end_island` and retained explicit
  negative evidence for unfinished random-world and formal gates.
- Added a natural dynamic-dragon presence gate that observes the vanilla
  manager's AI-enabled motion without fixture spawning or freezing, and made
  active visible dragon-breath clouds fair proximity threats for emergency
  avoidance.
- Added a real MiMo inventory round-trip gate: the companion acquires an
  observed oak-log stack through vanilla pickup, accepts a second player-chat
  request, and drops the owned stack through the normal inventory THROW path.
  The controlled Forge 65.1.1 run passed; random Hardcore and formal M1--M4
  claims remain excluded.
- Narrowed the final model-visible schema to `drop_item` when the current fair
  self-inventory proves an explicit owned item/count, with an action-first
  playbook and no change to unrelated route or observation handoffs.
- Replayed the live pickup/drop gate on Forge 65.0.0 and 65.1.2; both patch
  slices passed with the same real MiMo model chain. This is patch evidence,
  not a complete Forge compatibility matrix or formal M1--M4 result.
- Added a separate player-gift round-trip GameTest. A real logged-in player
  gives three oak logs through vanilla `ServerPlayer.drop`; the companion
  picks them up and immediately drops them through the normal inventory THROW
  path. The first live run found and fixed the canonical `itemId` inventory
  field mismatch; the fixed Forge 65.1.1 MiMo run passed in 18.70 seconds.

0.1.10-dev-mc26.2
-----------------

- Added fresh authorized MiMo live slices for ordinary movement, follow,
  surprise-zombie defense, and owned golden-apple consumption; each required
  a model decision followed by vanilla body evidence.
- Recorded the dedicated-server lifecycle, two-boot persistence, and delayed
  first-human anchor smoke results without promoting missing Xvfb evidence.
- Kept public documentation English-only while allowing multilingual runtime
  chat and GameTest fixtures.
- Added fair multipart Ender Dragon collider-center perception and retained
  ordinary first-person line-of-sight evidence for every target point.
- Added a bounded melee burst followed by a ranged retreat in the dragon skill.
- Added transient recovery for child-shot races such as a blocked interaction,
  rejected look, interrupted use, and release failure.
- Expanded live and offline dragon diagnostics with target parts, visible
  projectiles, danger signals, revisions, arrows, and skill checkpoints.
- Added an observed 20-block crystal firing-lane search, an eight-tick
  first-person ranged retreat, and explicit End fall-recovery constraints.
- Verified a real MiMo model decision through crystal destruction, dragon
  death, and physical End return in the controlled Forge 65.1.1 GameTest.
- Kept controlled offline End-entry/dragon/return evidence separate from live
  model and formal random-seed claims.
- Reworked public project documentation to English-only and recorded the latest
  live MiMo victory/return evidence honestly.
- Bound functional and delayed-anchor evidence to a manifest-owned run nonce;
  missing, mixed, and internally consistent foreign-run bundles now fail.
- Disabled the incomplete ForgeGradle merged-main JavaCompile cache entry so a
  clean or fresh CI checkout always materializes production classes before
  compiling tests and packaging the exact JAR.
- Corrected the End fall-recovery policy: vanilla water remains usable in the
  End, while the Nether still rejects water and falls back to legal clutch
  materials. Observed surface, reach, alignment, and occupancy gates remain in
  force before the ordinary item-use path can deploy a bucket.
- Reopened one bounded close-range dragon melee window after every four
  completed ordinary arrows. This prevents a later perch from being ignored
  forever while preserving distance, line-of-sight, aim, cooldown, and burst
  limits for each attack.

Evidence policy
---------------

Release notes distinguish implementation, controlled physical tests, live-model
slices, and formal gates. No acknowledgement, historical run, or no-model
arena is a formal M0–M4 result. Original code is Apache-2.0; third-party
material keeps its own license.
