# Final release verification

The final release is allowed only when M0–M4, all required Forge lines, exact
JAR/client hashes, security audit, performance budgets, and evidence manifests
are green. A dirty checkout, missing provider, missing client renderer, or
partial fixture run is not a release.

Current release status: `NON_RELEASE`; M0, M1, M2, M3, M4 and all formal gates
are `NOT_RUN`. The authoritative machine-readable state is
[GOAL_STATE.json](../progress/GOAL_STATE.json). The current installable JAR is
a development artifact, not a final professional game-companion release.
